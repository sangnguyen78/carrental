# Car Rental — Giao diện người dùng

Đây là repository frontend cho dự án **Car Rental**, hướng đến việc cung cấp giao diện người dùng cho hệ thống thuê xe. Frontend dự kiến kết nối với backend API tại repository [`apicarrental`](https://github.com/sangnguyen78/apicarrental).

## Các repository của dự án

- **Frontend:** [sangnguyen78/carrental](https://github.com/sangnguyen78/carrental)
- **Backend API:** [sangnguyen78/apicarrental](https://github.com/sangnguyen78/apicarrental)

Backend hiện có API REST và GraphQL cho quản lý người dùng và xác thực. Xem README của [`apicarrental`](https://github.com/sangnguyen78/apicarrental#readme) để biết hướng dẫn cài đặt và các endpoint đang có.

## Trạng thái

README này giới thiệu mục đích và mối liên hệ giữa frontend với backend. Hiện nhánh `main` chưa có mã nguồn ứng dụng hoặc tệp cấu hình package được theo dõi, nên framework frontend, các tính năng giao diện và lệnh chạy chưa được xác nhận. Phần hướng dẫn cài đặt sẽ được bổ sung khi mã nguồn frontend được thêm vào repository.

## Tích hợp API

Khi triển khai kết nối, hãy cấu hình frontend sử dụng địa chỉ backend API phù hợp với môi trường phát triển hoặc triển khai. Không đưa thông tin xác thực hay khóa bí mật vào mã nguồn công khai.

## Đóng góp

Các đóng góp được hoan nghênh. Hãy mở issue để trao đổi về thay đổi lớn, tạo branch riêng cho công việc và gửi pull request kèm mô tả mục đích, thay đổi chính và cách kiểm thử.

## Giấy phép

Chưa xác định giấy phép riêng cho repository frontend. Hãy thêm tệp `LICENSE` khi chủ sở hữu dự án quyết định và công bố điều khoản sử dụng cho mã nguồn tại đây.
