# Car Rental — Giao diện người dùng

Repository này dành cho phần **frontend** của dự án Car Rental, dự kiến cung cấp giao diện để người dùng tương tác với hệ thống thuê xe. Mã nguồn frontend chưa được đăng tải trong repository này.

## Trạng thái dự án

Đây hiện là repository giới thiệu dự án và mối liên hệ với backend. Mã nguồn cũ không được đưa lên đây; không đăng tải mã nguồn, tài liệu, hình ảnh hoặc tài sản thuộc công ty cũ nếu chưa có quyền sử dụng và công bố.

Khi có mã nguồn frontend mới do chủ sở hữu tạo hoặc được phép công bố, README sẽ được cập nhật thêm công nghệ, hướng dẫn cài đặt, cấu hình API, cách chạy và ảnh minh họa.

## Các repository của dự án

- **Frontend:** [sangnguyen78/carrental](https://github.com/sangnguyen78/carrental) — repository hiện tại.
- **Backend API:** [sangnguyen78/apicarrental](https://github.com/sangnguyen78/apicarrental).

Backend hiện có API REST và GraphQL tập trung vào quản lý người dùng và xác thực. Xem [README của `apicarrental`](https://github.com/sangnguyen78/apicarrental#readme) để biết phạm vi chức năng và hướng dẫn chạy backend. Chưa nên giả định rằng các API quản lý xe hoặc đặt thuê đã được triển khai.

## Hiện trạng mã nguồn

Hiện repository chưa có mã nguồn ứng dụng frontend, tệp cấu hình package hay hướng dẫn chạy ứng dụng. Vì vậy, chưa có lệnh cài đặt hoặc chạy dự án frontend để cung cấp ở thời điểm này.

## Đóng góp

Các đóng góp liên quan đến README hoặc định hướng phát triển được hoan nghênh. Với thay đổi lớn, vui lòng mở issue để trao đổi trước; sau đó tạo branch riêng và gửi pull request kèm mô tả mục đích, nội dung thay đổi và cách kiểm tra.

Không gửi mã nguồn, tài liệu, hình ảnh hoặc thông tin thuộc bên thứ ba nếu chưa có quyền công bố. Khi có mã nguồn, hãy bổ sung các bước kiểm thử phù hợp vào hướng dẫn đóng góp.
